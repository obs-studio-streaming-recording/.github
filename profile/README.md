## Troubleshooting Common Issues

Install issues? Run the configuration wizard before manually changing encoder settings.  
Performance problems? Lower bitrate or resolution when the stream reports dropped frames.  
License/activation? Check the audio mixer for muted or overdriven sources.  
Compatibility? Update the graphics driver when hardware encoding fails to initialise.  
Update failures? Use a wired connection for streaming to reduce instability.
